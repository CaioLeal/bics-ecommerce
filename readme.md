### 📍 Why this Project?

This project was developed as a comprehensive portfolio piece focused on **Full-Stack development and high-end UI/UX**, themed around BICS, a luxury fashion and lifestyle brand. The main goal was to build a complete, production-ready e-commerce platform featuring a dynamic public storefront and a robust, Single-Page Application (SPA) styled administrative dashboard.

The main technical differentiator of this application is the seamless integration between a visually stunning front-end and a complex relational back-end:
- **Dynamic Full-Stack Architecture:** Secure integration between the front-end and a PHP/MySQL back-end to handle users, nested categories, products, and advanced coupon systems.

- **Advanced Media Handling:** A sophisticated product gallery supporting multiple image and video uploads simultaneously, rendering dynamically in a responsive, mixed-media carousel.

- **SPA Admin Dashboard:** An interactive, zero-reload administrative panel built with modular JavaScript and PHP, allowing seamless management of inventory, dynamic hex-color selectors, real-time stock, and complex discount rules.

- **Premium UI/UX Design:** Pixel-perfect CSS styling matching luxury market standards, including fluid animations, interactive floating labels, color-coded status badges, and an automated discount calculation system.

### ⭐ How to use this project locally?

To run this full-stack project on your machine, you will need a local server environment like **XAMPP**, **WAMP**, or **MAMP** since it uses PHP and MySQL.

1. **Clone** this repository into your local server's root folder (e.g., `C:/xampp/htdocs/bics`):
```bash
git clone https://github.com/CaioLeal/BICS-Ecommerce
```

2. Open your local server control panel (e.g., XAMPP) and start the **Apache** and **MySQL** modules.

3. Access your database manager (usually `http://localhost/phpmyadmin`), create a new database named `bics_db`, and run the SQL commands provided in the project to set up the tables (Users, Products, Categories, Coupons, Sales).

4. Finally, open your browser and navigate to the project folder to see it running:
```text
http://localhost/bics/index.php
```
